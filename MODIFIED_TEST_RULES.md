# Modified test and check rules (Grade 3)

Use these rules for every modified test and check. The code lives in `modified_test_kit.py`.

1. One question per page. Lots of white space. Nothing decorative.
2. Big, plain print: questions 17 pt, choices 16–20 pt. Short lines, one idea per line.
   Students read alone, so use the fewest words.
3. Key numbers and words in **bold**. Use color only when the word names a color (yellow strip, red strip).
4. Give every question one picture that shows the math: a strip diagram, groups, a table or a place-value chart.
5. Give one "Do this" step on a grey band, then the answer choices. No extra helper boxes.
6. Paper test: 3 answer choices (remove the most obviously wrong one), with big lettered bubbles.
7. Computer helper sheet: the same picture and step, with all 4 choices listed 1st–4th in the computer's order.
8. Keep the original numbers and question numbers.

## Simplified level (more support than Modified)
- 2 answer choices: the correct answer and the closest wrong answer.
- About one short line of words. The picture tells the story.
- The picture is partly filled in, and students do one small fill-in before picking.
- Bigger print (20–24 pt).
